Gunsheild

A small project I'm building to detect potentially suspicious and phishing messages.

The idea is simple: paste a message, analyze it, and get an indication of whether it might contain phishing attempts or suspicious links. I'm building this to improve my coding skills and understand how phishing detection works.

This project is still under development. Some features are incomplete, and the detection logic is still being worked on.

 What it does??
 Analyzes messages for suspicious patterns,Assigns a risk score based on detected indicators,Displays findings to help explain why a message might be suspicious, Provides a simple web interface.

 Built with

- HTML
- CSS
- JavaScript
